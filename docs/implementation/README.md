# 完整 AI 量化交易系统：实施规划总索引

版本：1.0｜编写日期：2026-11-07｜状态：待实施的技术规划，不是已实现功能，也不是收益承诺。

## 先回答：完整系统究竟还需要什么？

完整系统不是“把行情交给大模型，让它说买卖”。它应是一条可追溯、可重放、可拒绝执行的链路：

**合法且可追溯的数据 → 时点正确的特征 → 有明确假设的策略 → 独立样本外验证 → 组合目标 → 账户级风控与资金预占 → 可靠订单执行 → 成交/费用/持仓账本 → 对账 → 监控、停机、恢复。**

AI 是其中一个可替换的信号增强模块：传统机器学习负责概率/收益/风险预测；大模型负责文本事件抽取和研究解释。**AI 不拥有 broker、实盘凭证、交易开关、风控参数或部署权限。**

对本项目，推荐先完成单账户、单写入者、美股/ETF、USD、只做多、常规交易时段的模拟交易闭环。MVP 用确定性的 5 分钟突破策略做对照；通过数据和回测验收后，才比较机器学习过滤器；大模型文本特征最后进入 shadow 验证。实盘是单独审批的后续项目，不能通过改一个布尔值开放。

## 状态与名称约定

- **现有**：已在当前工作树中找到的代码或上轮已运行的证据；不等于生产可用。
- **新增**：本规划要求建设的模块/表/API；文中新增路径不是现有文件链接。
- **建议初值**：用于实现与验证的工程参数，不是投资建议，也不是优化所得最优值。
- **必须复核**：依赖账户类型、司法辖区、供应商版本/许可的外部事项。
- 示例账户只用 `paper-account-1` 内部标识；不在文档/日志写真实 IB 账号。
- 文中时间窗口用 `America/New_York` 解释市场时段，持久化使用 UTC；金钱/数量使用十进制定点/Decimal；模型特征允许 float 但必须检查有限性。
- API、配置、函数和表结构都是目标设计，除明确标记“现有”的部分外不可当作可直接运行的命令。

## 统一的基线决策

这些值供全套文档引用；任何专题若需改变，应先更新这里及 ADR，而不是各写一套。

| 项目 | 规划基线 |
|---|---|
| 完整 MVP 的范围 | 单账户、单 worker 写入；美股/ETF、STK/SMART/USD、只做多、整股、RTH |
| 原始/决策周期 | 1 分钟基准 bar，聚合 5 分钟决策 bar；IB BBO 用于实际入场检查 |
| 算法基准 | `MomentumBreakoutV1`，规则见 03；其盈利能力未知 |
| 控制默认 | PAPER、只读、PAUSED；无完整新鲜上下文则拒绝开仓 |
| 当前仓库风控初值 | 日损 1% NAV、总 gross 20%、单标的 5%、最多 3 标的、单笔 stop-risk 0.25%、价差 0.30%=30 bps |
| 报价/账户初值 | BBO 最旧一侧 ≤10 秒；账户快照 ≤15 秒且当次完整；原始输入未来时间拒绝 |
| 小额 Paper 试单额外帽子 | 每个入场最多 1 整股且名义额 ≤500 USD；价格高于 500 则跳过，不改上限绕过 |
| Paper 观察最低样本 | 至少 30 个完整交易日，且至少 100 个完成 round trip；两者都满足仍不自动通过 |
| 研究晋级最低样本 | 拼接外层 OOS 至少 252 个交易日、200 个完成 round trip；不足则 INCONCLUSIVE，不降低标准凑通过 |
| LLM 默认位置 | 异步研究/文本抽取；不在订单必经同步路径，不参与算钱或提升风险上限 |
| 失败行为 | 无新单；存量保护与严格 reduce-only 路径由确定性代码处理；恢复不自动 ACTIVE |

1% 日损阈值、止损价、保护单都不能保证损失被限制在该数值：跳空、停牌、流动性、系统故障会突破预算。

## 当前进度的准确理解

现有基础：IB 账户/只读保护、行情 BBO 新鲜度、订单幂等入口、部分确定性风控、对账和控制 API。上一轮结果为 482 项通过，显式只读 IB 连接/快照测试通过。**这些数字是已有重构的证据，不是本次规划功能已被实现的证据。**

核心缺口：合格历史数据、真实账户/购买力快照、账本与组合投影、挂单预占、保护单组、自动恢复 supervisor、确定性策略、可回放回测、AI 训练评测、生产观测与操作验收。当前已有 `signals`、`risk_decisions`、`positions` 表，不代表对应闭环已经接通。
